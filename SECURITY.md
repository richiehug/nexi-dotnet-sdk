# Security

Do not submit security-sensitive findings through public GitHub Issues.

Use [GitHub Private Vulnerability Reporting](https://github.com/richiehug/opi-dotnet-sdk/security/advisories/new) when enabled. If the private reporting form is unavailable, use the contact route on [richiehug.com](https://richiehug.com) to request a private reporting channel before sending vulnerability details or sensitive attachments.

Provide the affected SDK version and edition, impact, and a minimal reproduction using synthetic data. Version 1.0.0 is the current supported release; review and fixes are best effort, with no guaranteed response or remediation timeline.

Do not include PAN/card data, passwords, API keys, merchant or terminal credentials, personal data, sensitive transaction data, or full production logs in public reports. Sanitize diagnostics before sharing them privately as well.

Payment-provider and terminal infrastructure incidents should also be reported directly to the relevant provider through its private incident channel.
