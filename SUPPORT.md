# Support

OPI .NET SDK is independently maintained by Richard Hug ([richiehug.com](https://richiehug.com)).

Submit bugs and feature requests through [GitHub Issues](https://github.com/richiehug/opi-dotnet-sdk/issues). Include SDK edition/version, Windows and .NET versions, terminal model/application/firmware, a minimal reproduction and sanitized diagnostics.

Issues are reviewed on a best-effort basis. There is no SLA, guaranteed response time, resolution time or release schedule. Opening an issue does not create a support obligation or a commitment to implement a feature or fix.

Payment processing, acquiring, terminal provisioning, merchant configuration, payment infrastructure and provider-specific production incidents must be handled with the relevant payment service provider or terminal provider. This project does not provide those operational services.

For security-sensitive findings, follow [SECURITY.md](SECURITY.md). Never post card data, credentials or sensitive production logs in issues.
