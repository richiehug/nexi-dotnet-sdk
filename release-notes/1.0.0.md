# 🎉 OPI .NET SDK is out!

OPI .NET SDK 1.0.0 brings OPI payment integration to Windows POS and ECR applications. Connect to a network terminal while the SDK handles TCP communication, XML messages, terminal callbacks, and transaction results.

## Highlights in 1.0.0

- `OpiClient` and `OpiOptions` in the `Opi.Sdk` namespace, distributed as `Opi.Sdk.dll`.
- Full for .NET 10 and Lite for .NET Framework 4.8/4.8.1, with the same public payment and event contract.
- Payments, refunds, reversals, and terminal operations.
- Transaction results, receipts, DCC information, and status events.
- Explicit abort, reprint, and repeat-last-message commands.
- Optional SDK diagnostics with normal and extended log levels; logging is off by default.
- Your application owns the payment screen and transaction experience. The SDK contains no overlay or branding components.
