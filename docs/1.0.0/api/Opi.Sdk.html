Opi.Sdk

Start with OpiClient and OpiOptions, then explore the result and receipt types you need. For an end-to-end example, see the integration guide.

Start here

API Purpose
OpiClient Create the terminal client and call payments, recovery and terminal operations.
OpiOptions Configure the connection, timeouts, receipts, logging and optional UI.
PaymentRequest Supply the amount, currency and merchant reference.

Results and errors

API Purpose
OpiResult Read the outcome and correlation ID.
ResultState Interpret success, rejection, cancellation and uncertainty.
OpiError Handle stable error categories.
TransactionResult Access financial details for the transaction.
TerminalInformation Read terminal identity, status and capabilities.
DccDetails Read dynamic currency conversion details.

Receipts

API Purpose
ReceiptHandling Choose routing for merchant and customer copies.
ReceiptHandlingMode Print at the terminal, return to the app or suppress a copy.
ReceiptDetails Access the two receipt copies in a result.
Receipt Read receipt text and its content type.
ReceiptType Identify the merchant or customer copy.

Events and operations

API Purpose
OperationEvent Follow lifecycle, receipt and recovery notifications.
OperationEventKind Identify what an event represents.
OpiOperation Identify the financial or terminal operation.

Optional UI

API Purpose
ITransactionOverlay Implement a custom transaction presentation adapter.

Windows overlay adapters

Full only (.NET 10 Windows): Opi.Sdk.Windows provides embedded and separate-window adapters inside the Full Opi.Sdk.dll. Lite targets .NET Framework 4.8 and uses app-owned UI.
